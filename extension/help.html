Stripper hides recognized sponsored results, generative AI panels and shortcuts on Google, Bing, DuckDuckGo and Brave Search. You choose where it runs.

Install in Chrome, Edge or Brave

  1. Keep the extension folder somewhere permanent. If using the ZIP, extract it first.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode, click Load unpacked, and select the folder containing manifest.json.
  4. Pin Stripper from the extensions menu, then reload any search tabs you already had open.

There is no build step for installation. This is a local, unpacked release, not a Chrome Web Store listing.

Microsoft Edge

Use the same extension folder in Edge on Windows or macOS. No separate download or build is needed.

  1. Extract the ZIP into a folder you will keep.
  2. Open edge://extensions in Microsoft Edge.
  3. Enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.
  4. Show Stripper in the toolbar from Edge’s Extensions menu, then refresh your search tabs.

Edge has its own saved preferences. The same AI and sponsored-result controls apply to supported search pages, including Bing. Edge’s browser sidebar, new-tab feed and built-in Copilot button are outside the search-page filter.

For updates, replace the files in the same folder, click Reload on edge://extensions, and refresh your search tabs. Managed browsers may restrict unpacked extensions. This is not a Microsoft Edge Add-ons listing.

Firefox (142 or newer)

  1. Extract the Firefox ZIP, or use the project’s extension folder.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and select manifest.json.
  4. Allow search-site access if requested, then refresh search tabs and open Stripper from the Extensions menu.

This development installation lasts until Firefox restarts. Permanent installation on standard Firefox requires Mozilla signing. This package is unsigned; it has not been published to Firefox Add-ons. No browser security settings need to be disabled.

Firefox saves its own preferences. The AI and sponsored-result controls work on the same supported search pages. Firefox desktop 142 or newer is required; Android is not covered.

Your controls

Filtering is on / paused
Pause to immediately restore panels hidden by Stripper. It does not undo a previous URL redirect; choose All again after disabling Web-only mode.
Where it works
Enable or disable each engine independently. Filters apply on search pages and search homepages only.
Hide sponsored results
Hide recognized paid listings and sponsored product blocks. Enabled by default. Turn it off to restore those placements without changing AI filtering. This hides page elements; it does not block ad network requests or ads inside other websites.
Hide AI answers
Hide recognized generated overview and answer panels. Dynamically loaded panels are checked too.
Hide AI shortcuts
Hide recognized AI navigation links and buttons.
Skip AI search pages
Redirect supported AI search URLs to ordinary results, keeping the query where available. A Google AI Mode query opens the Web filter.
Google: web links only
Opt into Google’s Web filter for general searches. This also removes other rich result features. Explicit image, video, news, shopping and other search filters are preserved.

What it can—and cannot—filter

Stripper targets visible search-engine AI features. It does not identify AI-written websites, remove every AI-generated image, disable ranking algorithms, or prevent the search engine from generating content behind the scenes.

Search engines change their layouts and run regional experiments. A new or translated panel may slip through. Google’s Web-only option is an additional fallback. Bing, DuckDuckGo and Brave rules cover known structures and labels; they need continued testing as layouts change.

Supported Google domains include google.com, google.com.ng, google.co.uk and other common regional domains listed in the manifest. Other Google services are not filtered. Standalone chat services such as copilot.microsoft.com and duck.ai are outside scope.

Privacy, in plain language

All filtering runs on your device. Stripper makes no network requests, has no analytics, and sends no search queries anywhere. Preferences are saved in your browser’s local extension storage, not synced to the cloud. The hidden count is calculated for the current page and is not stored.

The storage permission saves your preferences. activeTab lets the popup check the current tab when you open it. Site access lets the extension hide elements on the listed search domains. It does not request access to every website.

If something looks wrong

Pause filtering or disable the affected engine. Refresh the page if it was already open when you installed or updated Stripper. If an AI panel survives, try Google’s Web-only option or the search engine’s own AI settings. Updates to selectors require replacing these extension files and clicking Reload on the extensions page.
